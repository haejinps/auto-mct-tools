# AUTO MCT TOOLS

MCT 가공을 위한 프로그램 모음입니다. 런처 하나를 설치하면 필요한 프로그램을 골라서 설치 · 업데이트 · 삭제할 수 있습니다.

| 프로그램 | 설명 |
|---|---|
| Auto NC Viewer | NC 프로그램 편집 · 백플롯 · 가공 시뮬레이션 |
| Auto 3D Viewer | STL · STEP · IGES · DXF 3D 모델 뷰어 |
| Auto FaceMill | 페이스밀 · 외곽 각치기 · 오픈포켓 NC 자동 생성 |
| Auto Drill | DXF / DWG 도면에서 원 선택 → 드릴 NC 자동 생성 |

## 설치

1. [최신 런처 내려받기](https://github.com/haejinps/auto-mct-tools/releases/latest) 에서 `AUTO-MCT-TOOLS-Setup-x.y.z.exe` 를 내려받아 실행합니다.
2. 런처에서 원하는 프로그램의 **설치** 버튼을 누릅니다.

- Windows 10 / 11 (64비트), 관리자 권한 없이 설치됩니다.
- 새 버전이 나오면 런처에 **업데이트** 버튼이 표시됩니다.
- Windows 가 "PC 보호" 창을 띄우면 **추가 정보 → 실행** 을 누르세요.
